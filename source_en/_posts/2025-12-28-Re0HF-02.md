<h2>2. Four data formats supported by SFTT Trainer</h2>
<p>This is the focus of understanding SFTT Trainer.</p>
<h3>2.1 Format Comparison</h3>
<p><strong>Four data formats supported by SFTT Trainer</strong></p>
<h4>Format 1: Standard Language Modeling</h4>
<pre><code class="language-json">{&quot;text&quot;: &quot;The sky is blue.&quot;}
</code></pre>
<ul>
<li><strong>Apply scene</strong>: Pre-training, renewal of tasks</li>
<li><strong>Characteristics</strong>: token all calculations of Loss (no Los Masking)</li>
</ul>
<h4>Format 2: Periodic Landscape Modeling <strong>Recommendations</strong></h4>
<pre><code class="language-json">{&quot;messages&quot;: [
    {&quot;role&quot;: &quot;user&quot;, &quot;content&quot;: &quot;问题&quot;},
    {&quot;role&quot;: &quot;assistant&quot;, &quot;content&quot;: &quot;回答&quot;}
]}
</code></pre>
<ul>
<li><strong>Apply scene</strong>: Dialogue missions, chat model training</li>
<li><strong>Characteristics</strong>: Auto-applied bit template, auto-loss Masking</li>
</ul>
<h4>Format 3: Standard Prompt-Complement</h4>
<pre><code class="language-json">{&quot;prompt&quot;: &quot;问题&quot;, &quot;completion&quot;: &quot;回答&quot;}
</code></pre>
<ul>
<li><strong>Apply scene</strong>: A simple question and answer mission</li>
<li><strong>Characteristics</strong>: calculation of only part of the command</li>
</ul>
<h4>Format 4: Periodical Prompt-Complement</h4>
<pre><code class="language-json">{&quot;prompt&quot;: [{&quot;role&quot;: &quot;user&quot;, ...}],
 &quot;completion&quot;: [{&quot;role&quot;: &quot;assistant&quot;, ...}]}
</code></pre>
<ul>
<li><strong>Characteristics</strong>:Prompt-Complement completed with dialogue</li>
</ul>
<h3>2.2 Recommended format: messages (format 2)</h3>

<h2>3. Internal working principles of SFTT Trainer</h2>
<h3>3.1 Automated processing processes</h3>
<p>When you use the messages format, the SFTTrainer internal will:</p>
<p><strong>Processes</strong></p>
<pre><code class="language-mermaid">graph TD
    A[&quot;messages格式数据&lt;br/&gt;role: user/assistant&quot;] --&gt; B[检测数据格式]
    B --&gt; C[应用 chat_template]
    C --&gt; D[识别 assistant 回复边界]
    D --&gt; E[自动设置 labels]
    E --&gt; F[分词和 padding]
    F --&gt; G[训练就绪的 batch]
</code></pre>
<p><strong>Detailed steps</strong></p>
<ol>
<li><strong>Test Data Format</strong> ~ Found in messages format</li>
<li><strong>Apply chat template</strong> • Generate standardized dialogue formats</li>
<li><strong>Identify ansistant to border</strong> → Automatically recognize by special tag</li>
<li><strong>Autoset labels</strong> →prompt part set to -100, ansistant part set token ID</li>
<li><strong>Phrasing and peding</strong> • Format available for processing into models</li>
</ol>

<h2>Chat template</h2>
<h3>5.1 What's a chat template?</h3>
<p>Chat template is usually a Jinja2 template that defines how to format the dialogue into a text that the model understands:</p>
<pre><code>输入 messages:
[
    {&quot;role&quot;: &quot;user&quot;, &quot;content&quot;: &quot;你好&quot;},
    {&quot;role&quot;: &quot;assistant&quot;, &quot;content&quot;: &quot;你好！有什么可以帮你的吗？&quot;}
]

        ↓ 应用 chat_template ↓

输出文本:
&lt;|im_start|&gt;user
你好&lt;|im_end|&gt;
&lt;|im_start|&gt;assistant
你好！有什么可以帮你的吗？&lt;|im_end|&gt;
</code></pre>
<h3>5.2 Why do you need to define a carat template?</h3>
<p><strong>Problem</strong>: Not all models support <code>return_assistant_tokens_mask</code> Functions</p>
<p>The blogger says that the government is not a party to the law.<code>return_assistant_tokens_mask</code> The new Jinja2 template used for functionality may lead to incompatibility with other frameworks, and therefore, from a future perspective, this fit may well not continue.</p>
<p>This feature enables SFTTrainer to automatically identify the boundaries that are returned by antlert. Customizes are required if the model ' s default template is not supported.</p>
<p><strong>Qwen3</strong>：</p>
<ul>
<li>Default template not supported <code>generation</code> Keywords</li>
<li>Need to use modified template to enable <code>assistant_only_loss</code></li>
</ul>
<h3>5.3 Custom template example</h3>
<p>Customize the template approach to using the components generated by the keywords assistant on the basis of the original template, so that the SFTTrainer can mask them by using the keyword.</p>
<pre><code class="language-jinja">{% raw %}
{#- 自定义 template 的关键部分 -#}
{%- for message in messages %}
    {%- if message[&#39;role&#39;] == &#39;assistant&#39; %}
        &#123;&#123;- &#39;&lt;|im_start|&gt;assistant\n&#39; &#125;&#125;
        {%- generation %}  {# ← 这个标签告诉 SFTTrainer 这是要训练的部分 #}
            &#123;&#123;- message[&#39;content&#39;] + &#39;&lt;|im_end|&gt;&#39; &#125;&#125;
        {%- endgeneration %}
    {%- endif %}
{%- endfor %}
{% endraw %}
</code></pre>
