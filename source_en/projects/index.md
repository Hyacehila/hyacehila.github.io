<h2 class="gallery-title not-markdown" id="gallery-lenny-compass-title"><span data-i18n="gallery-lenny-compass-title">Lenny Compass</span></h2>
<p class="gallery-description" id="gallery-lenny-compass-description"><span class="gallery-preview" hidden></span><span class="gallery-full" data-i18n="gallery-lenny-compass-desc">Lenny Compass helps readers answer product questions using Lenny’s articles and podcasts, with original passages available to check each claim. <h2 class="gallery-title not-markdown" id="gallery-analysisposts-title"><span data-i18n="gallery-analysisposts-title">AnalysisPosts</span></h2>
<p class="gallery-description" id="gallery-analysisposts-description"><span class="gallery-preview" hidden></span><span class="gallery-full" data-i18n="gallery-analysisposts-desc">AnalysisPosts combines statistical patterns in posts with external facts to produce public-opinion reports whose conclusions can be traced to evidence. A data agent analyzes labeled records with quantitative tools, a search agent gathers external facts, and a coordinator organizes further evidence gathering, cross-examination and conflict detection. This workflow addresses the narrow evidence base of a single-agent analysis. Core report claims are linked to sources and revisited by a verification agent. A visual interface exposes task steps, tool inputs and outputs, and scheduling paths, so users can investigate how a conclusion was reached or locate a problem in the analysis.</span> <button class="gallery-toggle" type="button" aria-expanded="true" aria-controls="gallery-analysisposts-description" hidden><span class="gallery-more" data-i18n="gallery-more">More</span><span class="gallery-less" data-i18n="gallery-less">Less</span></button></p>

<h2 class="gallery-title not-markdown" id="gallery-novel-eval-title"><span data-i18n="gallery-novel-eval-title">Novel Evaluation</span></h2>
<p class="gallery-description" id="gallery-novel-eval-description"><span class="gallery-preview" hidden></span><span class="gallery-full" data-i18n="gallery-novel-eval-desc">This local fiction-evaluation system produces reports with explicit criteria and inspectable judgments, helping readers understand scores and reuse a rubric across works. It screens the input, selects an analysis mode, identifies the work’s type and scores eight dimensions, then adds type-specific assessments and checks consistency before compiling the report. Users can review individual judgments, adjust prompts and criteria, and compare results through saved history. Task creation, batch evaluation, output-schema validation and regression tools support repeated checks of the evaluation process. The report exposes the reasoning behind the overall score so that its criteria and tradeoffs can be discussed and revised.</span> <button class="gallery-toggle" type="button" aria-expanded="true" aria-controls="gallery-novel-eval-description" hidden><span class="gallery-more" data-i18n="gallery-more">More</span><span class="gallery-less" data-i18n="gallery-less">Less</span></button></p>
