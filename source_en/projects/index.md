<h2 class="gallery-title not-markdown" id="gallery-lateron-title"><span data-i18n="gallery-lateron-title">LaterOn</span></h2>
<p class="gallery-description" id="gallery-lateron-description"><span class="gallery-preview" hidden></span><span class="gallery-full" data-i18n="gallery-lateron-desc">LaterOn turns scattered research pages into a project library that readers can return to, reducing tab clutter and repeated searches. I extended its collection and reading workflow with AI-assisted organization: pages are saved first, then read and assigned using project names and descriptions. Extraction can run locally in the browser or through a remote service; classification supports Chat models and decision-model interfaces such as Jev and OpenAI Decisions. Pages without a clear match remain in the inbox for manual review. Full-screen and sidebar views preserve reading status and scroll position. It addresses the same organizing problem as AutoTabGroups: LaterOn supports a lasting, separate library, while AutoTabGroups organizes native tab groups in the current browsing window.</span> <button class="gallery-toggle" type="button" aria-expanded="true" aria-controls="gallery-lateron-description" hidden><span class="gallery-more" data-i18n="gallery-more">More</span><span class="gallery-less" data-i18n="gallery-less">Less</span></button></p>

<h2 class="gallery-title not-markdown" id="gallery-autotabgroups-title"><span data-i18n="gallery-autotabgroups-title">AutoTabGroups</span></h2>
<p class="gallery-description" id="gallery-autotabgroups-description"><span class="gallery-preview" hidden></span><span class="gallery-full" data-i18n="gallery-autotabgroups-desc">AutoTabGroups organizes scattered pages in the current window into native browser tab groups, reducing manual sorting. It uses page titles, descriptions and optional body text alongside group names and descriptions to choose a destination. Existing groups take priority, with new groups created when requested. Already grouped pages keep their placement, and uncertain matches remain untouched. Users can inspect reasons and candidate scores, correct assignments, request a new judgment or undo the latest grouping change. Page reading and classification are configured separately, with Chat and decision-model options. Like LaterOn, it explores AI-assisted webpage organization. AutoTabGroups works directly with Chrome tab groups for active browsing tasks; LaterOn uses a separate project library for saved material and later reading.</span> <button class="gallery-toggle" type="button" aria-expanded="true" aria-controls="gallery-autotabgroups-description" hidden><span class="gallery-more" data-i18n="gallery-more">More</span><span class="gallery-less" data-i18n="gallery-less">Less</span></button></p>
